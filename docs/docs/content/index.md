# Introduction

[![patra](images/logo.svg)](https://github.com/appzenowebservices/Omnipost)

patra is a self-hosted, high performance one-way mailing list and newsletter manager. It comes as a standalone binary and the only dependency is a Postgres database.

[![patra screenshot](https://user-images.githubusercontent.com/547147/134939475-e0391111-f762-44cb-b056-6cb0857755e3.png)](https://github.com/appzenowebservices/Omnipost)

## Developers
patra is a free and open source software licensed under AGPLv3. If you are interested in contributing, check out the [GitHub repository](https://github.com/appzenowebservices/Omnipost) and refer to the [developer setup](developer-setup.md). The backend is written in Go and the frontend is Vue with Buefy for UI.
