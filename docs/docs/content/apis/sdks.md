# SDKs and client libraries

A list of 3rd party client libraries and SDKs that have been written for patra APIs.

!!! note
	The list is community sourced. They have not been verified and are not officially supported.

- [WordPress - WooCommerce plugin](https://github.com/post-duif/integration-patra-wordpress-plugin) integration for patra
- [patra ](https://github.com/mikeckennedy/patra) — Python API client
- [patra-api](https://github.com/Knuckles-Team/patra-api) — Python API client
- [frappe_patra](https://github.com/anandology/frappe_patra) — Frappe framework integration for patra
- [auto-newsletter-patra](https://github.com/chaddyc/auto-newsletter-patra) — Ghost CMS integration
- [patra-newsletter](https://github.com/iloveitaly/patra-newsletter) - RSS to patra integration for email newsletters
- [patra-crysctal](https://github.com/russ/patra-crystal) — Crystal lang API client
- [terraform-provider-patra](https://github.com/Muravlev/terraform-provider-patra) — Manage patra templates in Terraform
- [patra-php-client](https://github.com/arunnabraham/patra-php-client) — PHP API client
- [php-patra](https://github.com/junisan/php-patra) — PHP API client
- [go-patra](https://github.com/EzeXchange-API/go-patra) — Go API client
- [patra-ruby](https://github.com/polydice/patra-ruby) — Ruby API client
- [patra-nodejs-api](https://github.com/mihairaulea/patra-nodejs-api) — NodeJS API client
- [@maloma/patra](https://codeberg.org/maloma/patra-sdk) — NodeJS/Bun Typescript SDK
- [patra-laravel](https://github.com/theafolayan/patra-laravel) — Laravel API Client
- [nuxt-patra](https://github.com/roncallyt/nuxt-patra) — Patra module for Nuxt.js
- [patra-japi](https://codeberg.org/hlassiege/patra-japi) - Patra client for Java/kotlin
- [patra-mcp](https://github.com/rhnvrm/patra-mcp) — MCP (Model Context Protocol) server for Claude integration
- [N8N Nodes](https://github.com/wiesinghilker/n8n-nodes-patra) — Adds Patra Nodes for N8N Automations
